ClipVault: clipboard history for iPhone

iOS keeps only one thing on the clipboard. ClipVault keeps a searchable history you can pin, and paste back from four places: the app, the share sheet, a custom keyboard and a Home Screen widget. Everything stays on the device, with no server, account or analytics.

📱 App📤 Share sheet⌨️ Keyboard🧩 Widget
  • Built around iOS limits. iOS can't report copies in the background, so ClipVault saves only on user action: the system Paste button (no "Allow Paste" alert), the share sheet, a Shortcut or Action button, or when the app or keyboard is open.
  • Four targets, one shared core. App, Share extension, Keyboard extension and WidgetKit widget share one SwiftData store through an App Group, using a local Swift package (ClipKit) with 53 automated tests.
  • Privacy by default. One-time codes and card numbers (Luhn check) are masked, hidden from the widget and deleted after 10 minutes. Optional Face ID lock for the app.
  • Memory-aware keyboard. Text-only rows, capped at 50, with full text loaded only on tap, to stay inside the extension memory budget. It degrades clearly when Full Access is off.
  • Shortcuts and Siri. App Intents to save or copy a clip, usable from the Action button and widget taps. Built with Swift 6 strict concurrency, with a string catalog ready for translation.

Smart Inventory: asset scanning & onboarding

An iOS app built in Swift for tracking assets end to end. Point the camera at a QR code or barcode and the app identifies the asset in an instant. If the code is already registered, you get its full details. If it isn't, the same scan takes you straight into onboarding, so a new asset goes from a physical label to a complete record in one flow.

  • Scan to identify. Live QR and barcode scanning with AVFoundation, with the camera preview, scan area and result handling built natively.
  • Onboard new assets. An unregistered code opens an onboarding form with the scanned code pre-filled as the asset ID. Add the asset's name, category, location and status, then save.
  • View and manage details. A registered asset opens a details screen, so its information can be reviewed and kept up to date.
  • Built for speed in the field. One scan, one screen: no typing IDs by hand, which keeps records consistent.

TrackIn-out Auto-Scheduler

An iOS app for checking in to an inspection and checking out again, with an auto check-out scheduler that closes the session after a set time, even if the user forgets. The flow is monotonic: a session only moves forward (checked out → checked in → checked out), so records can't end up in an impossible state.

  • Check in to an inspection. One tap starts the session and records the check-in.
  • Auto check-out after a set time. When you check in, a deadline is scheduled. When it passes, the app checks you out automatically.
  • Works offline, and can't be cheated with the phone clock. Elapsed time is measured with a monotonic clock, not the wall-clock date and time. It needs no network, and changing the phone's date or time doesn't lengthen or shorten a session.
  • Accurate activity tracking. Check-in and check-out are driven by real elapsed time, so the recorded duration stays trustworthy.
